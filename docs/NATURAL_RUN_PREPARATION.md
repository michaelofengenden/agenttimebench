## What must remain true

The natural attempt starts independently, with fresh home, configuration,
workspace, memory, browser and simulator state. Use the same frozen objective,
permitted materials and intended target seen by the forecaster. A changed target
is recorded as a pairing difference, never repaired by rewriting the forecast.

There is no requested duration, experiment time cap or target score for voluntary
completion. Native task endpoints remain, including YC's simulated year or
bankruptcy. Setup and grading have separate timestamps. Count owned work and
waits once in elapsed time; do not sum subagent durations. Generate and qualify
the native terminal boundary according to [the protocol](PROTOCOL.md). A final
perfect score does not reveal when the task first became correct.

Keep wrong answers, refusals and voluntary early finishes. Continue an affected
session when the qualified recovery route permits it. A fresh replacement is
allowed only for confirmed external infrastructure failure, unavailable
continuation and proof that the original stopped. One replacement remains the
limit. Unknown live work continues to block switching evaluated agents.

The observed natural runtime is M. Short and long durations stay unset until we
choose the comparable observations and averaging rule. Forecast values never set
deadlines, resources, task order or calibration values.
