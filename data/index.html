How the files are made

A build step reads the live data by naming the fields it is allowed to export, never by copying a record and deleting fields it should not have kept. Every run on this site, and every run in these files, is the same run.

The build never reads account, host, worker, spend or billing fields, internal identifiers, raw prompts, or any free-text note.

Six Claude Fable 5.1 ProgramBench runs that refused within 30 seconds are recorded but marked in_default false, so a plain sum of the files matches the numbers shown across the rest of the site. See Method for how a run is timed and how the timing error is computed.

Release notes

  • 29 Sep 2026: recovered checkpoint completion

    Claude Fable 5.1, HumanEval, 30-hour request. Website completion uses the 24 September attempt's recorded CLI duration of 28 h 33 min and the separately graded checkpoint saved on 20 September (91 of 164 passed, about 55%). No verified grade was recovered for the later attempt. Timing is an estimate because the full-process end receipt is missing. Frozen prompts, chat template, greedy decoding, output limit and scorer were preserved for grading. Grading used Transformers on a Mac GPU instead of vLLM on CUDA; this backend difference may affect outputs. The paper's existing figures remain unchanged.
